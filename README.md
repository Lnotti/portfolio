## How to use it

Just open `index.html` in a browser. Everything else is baked in.

- Click projects to see details and images
- Filter by tags at the top
- Game projects are playable directly in the panel

## Technologies

- Vanilla JavaScript (no frameworks)
- CSS Flexbox for layout
- No external dependencies beyond Google Fonts

Built without bloat because I prefer things that load fast and I don't know how to properly use web tools.
